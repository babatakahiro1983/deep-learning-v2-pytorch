# Amazon SageMakerを使用した感情分析ウェブアプリケーション

## プロジェクト概要

このプロジェクトでは、Amazon SageMakerを活用して、映画レビューの感情（ポジティブ/ネガティブ）を分析するエンドツーエンドの機械学習ソリューションを構築します。ユーザーがウェブページ上で映画レビューを入力すると、デプロイされたモデルがそのレビューの感情を予測する仕組みを実装します。

## 使用データセット

このプロジェクトでは、スタンフォード大学のIMDbデータセットを使用しています。データセットには、25,000件のトレーニングレビュー（ポジティブ12,500件、ネガティブ12,500件）と25,000件のテストレビュー（ポジティブ12,500件、ネガティブ12,500件）が含まれています。

## 実装アプローチ

プロジェクトは以下の主要なステップに分かれています：

1. **データの取得と前処理**:
   - IMDbデータセットのダウンロードと読み込み
   - HTMLタグの除去、トークン化、ストップワードの除去、ステミング
   - 高頻度単語に基づく辞書の作成（語彙サイズ5,000）
   - 各レビューを固定長（500単語）の整数シーケンスに変換

2. **モデルの構築と訓練**:
   - PyTorchを使用したLSTM（Long Short-Term Memory）ベースの感情分析モデルの実装
   - Amazon SageMakerでのモデル訓練
   - 訓練スクリプトのカスタマイズ

3. **モデルのデプロイとテスト**:
   - SageMakerエンドポイントへのモデルデプロイ
   - デプロイされたモデルを使用したテストデータの評価

4. **ウェブアプリケーションの構築**:
   - AWS Lambda関数の作成とIAMロールの設定
   - Amazon API Gatewayを使用した公開APIの作成
   - ウェブインターフェースの実装

## LSTMモデルのアーキテクチャ

このプロジェクトで使用されるLSTMモデルの構造は以下の通りです：

1. **入力層**: レビューの単語IDシーケンス（単語辞書から変換）
2. **埋め込み層**: 各単語IDを固定次元のベクトルに変換
3. **LSTM層**: シーケンス情報を処理し、時間的依存関係を学習
4. **全結合層**: LSTM層の出力から最終予測（0または1）を生成
5. **シグモイド活性化関数**: 最終的な感情スコア（0〜1）を出力

## LSTMの技術詳細

### LSTMとは
長短期記憶（LSTM）ネットワークは、通常のリカレントニューラルネットワーク（RNN）の一種で、長期的な依存関係を学習する能力が強化されています。LSTMは、勾配消失問題を軽減し、テキストデータのような長いシーケンスを効果的に処理できます。

### LSTMの構造
LSTMセルには以下のコンポーネントが含まれます：

1. **忘却ゲート**: どの情報を捨てるかを決定
2. **入力ゲート**: 新しい情報をどの程度セルに追加するかを決定
3. **セル状態**: 長期記憶を保持
4. **出力ゲート**: 更新されたセル状態から何を出力するかを決定

### モデルのハイパーパラメータ

- **埋め込みサイズ**: 32
- **隠れ層のサイズ**: 200（訓練時）
- **語彙サイズ**: 5,000
- **学習率**: Adam最適化アルゴリズムを使用
- **損失関数**: バイナリクロスエントロピー

## AWSサービスの詳細解説

### Amazon SageMaker
Amazon SageMakerは、機械学習モデルを構築、訓練、デプロイするためのフルマネージド型サービスです。

#### SageMakerの主な特徴
- **ノートブックインスタンス**: Jupyter Notebookベースの環境で、データ探索とモデル開発が可能
- **訓練ジョブ**: スケーラブルな計算環境でモデルを効率的に訓練
- **ハイパーパラメータ最適化**: 自動的に最適なハイパーパラメータを発見
- **モデルデプロイ**: ワンクリックでRESTful APIを通じて利用可能なエンドポイントにモデルをデプロイ
- **マネージドスポットトレーニング**: コスト削減のためのスポットインスタンスの活用

#### このプロジェクトでのSageMakerの役割
- PyTorchベースのLSTMモデルのトレーニング環境提供
- GPUインスタンス（ml.p2.xlarge）を使用した効率的なモデルトレーニング
- モデルのホスティングと推論エンドポイントの提供
- モデルアーティファクトの管理

### AWS Lambda
AWS Lambdaは、サーバーの管理なしでコードを実行できるコンピューティングサービスです。イベントに応じて自動的にコードを実行し、必要に応じて自動的にスケールします。

#### AWS Lambdaの主な特徴
- **サーバーレスアーキテクチャ**: サーバー管理が不要
- **イベント駆動型**: APIリクエスト、ファイルの変更などのイベントでトリガー
- **自動スケーリング**: トラフィックに応じて自動的にスケール
- **課金モデル**: 使用したコンピューティング時間に対してのみ支払い
- **複数言語対応**: Python、Node.js、Java、Go、Rubyなど多言語サポート

#### このプロジェクトでのLambdaの役割
- ウェブアプリケーションとSageMakerエンドポイント間の橋渡し
- API Gatewayから受け取ったリクエストの処理
- SageMakerエンドポイントの呼び出しと結果の返却
- 入力データの前処理とレスポンスの整形

### Amazon API Gateway
Amazon API Gatewayは、任意の規模でAPIを作成、公開、管理、監視できるフルマネージド型サービスです。

#### API Gatewayの主な特徴
- **RESTful APIとWebSocket API**: 様々なタイプのAPIを作成可能
- **トラフィック管理**: スロットリングやキャッシュなどの機能
- **認証・認可**: IAM、Cognito、Lambda Authorizerを使用した認証
- **API監視**: CloudWatchとの統合によるモニタリング
- **APIステージの管理**: 開発、ステージング、本番環境などの管理

#### このプロジェクトでのAPI Gatewayの役割
- ウェブアプリケーションからアクセス可能な公開HTTP APIの提供
- クライアントリクエストのLambda関数へのルーティング
- CORSサポートによるクロスオリジンリクエストの処理
- クライアントとサーバー間の通信インターフェース提供

## AWSアーキテクチャとサービス統合

このプロジェクトでは複数のAWSサービスを統合しています：

1. **Amazon SageMaker**: モデルの訓練、テスト、デプロイを管理
2. **AWS Lambda**: ウェブアプリとSageMakerエンドポイント間の通信を処理
3. **Amazon API Gateway**: HTTPリクエストを受け取り、Lambda関数を呼び出すためのRESTful API
4. **Amazon S3**: トレーニングデータとモデルアーティファクトの保存
