# 自転車シェアリング予測プロジェクト分析

## プロジェクト概要

このプロジェクトは自転車シェアリングのデータを使用して、ニューラルネットワークを構築し、将来の自転車レンタル数を予測することを目的としています。実装されたニューラルネットワークは基本的なフィードフォワードネットワークで、入力層、隠れ層、出力層から構成されています。

## ニューラルネットワークの基本概念

### ニューラルネットワークの構造
ニューラルネットワークは、生物学的なニューロン（神経細胞）の仕組みを模倣した計算モデルです。基本的なニューラルネットワークは以下の要素で構成されています：

1. **ニューロン（ノード）**: 計算の基本単位で、入力を受け取り、活性化関数を通じて出力を生成します。
2. **層（レイヤー）**:
   - **入力層**: データが最初に入力される層
   - **隠れ層**: 入力層と出力層の間に位置し、複雑なパターンを学習する層
   - **出力層**: 最終的な予測値を出力する層
3. **重み（Weights）**: ニューロン間の接続の強さを表すパラメータ
4. **バイアス（Bias）**: 各ニューロンの活性化閾値を調整するパラメータ
5. **活性化関数**: 入力値を変換して出力値を生成する非線形関数（シグモイド、ReLU、tanh など）

### 前方伝播（Forward Propagation）
前方伝播は、入力データがネットワークを通過して出力を生成するプロセスです：

1. **数学的表現**:
   - 隠れ層の入力: $z^{[1]} = W^{[1]} \cdot X + b^{[1]}$
   - 隠れ層の活性化: $a^{[1]} = \sigma(z^{[1]})$
   - 出力層の入力: $z^{[2]} = W^{[2]} \cdot a^{[1]} + b^{[2]}$
   - 出力層の活性化: $a^{[2]} = f(z^{[2]})$

   ここで、$W$は重み行列、$b$はバイアスベクトル、$\sigma$は活性化関数（このプロジェクトではシグモイド関数）、$f$は出力層の活性化関数（このプロジェクトでは線形関数）です。

2. **具体的な計算ステップ**:
   - 各層で、前の層の出力と現在の層の重みの行列積を計算
   - バイアスを加える
   - 活性化関数を適用して出力を生成
   - 最終層まで繰り返す

### 誤差逆伝播（Backpropagation）
誤差逆伝播は、ネットワークの予測誤差を最小化するために重みを更新するプロセスです：

1. **計算の流れ**:
   - 出力誤差の計算: $L = \frac{1}{2}(y - \hat{y})^2$（二乗誤差の場合）
   - 出力層の誤差: $\delta^{[2]} = -(y - \hat{y}) \cdot f'(z^{[2]})$
   - 隠れ層への誤差の逆伝播: $\delta^{[1]} = (W^{[2]})^T \cdot \delta^{[2]} \cdot \sigma'(z^{[1]})$
   - 重みに関する勾配: $\nabla_{W^{[1]}} L = \delta^{[1]} \cdot X^T$、$\nabla_{W^{[2]}} L = \delta^{[2]} \cdot (a^{[1]})^T$
   - バイアスに関する勾配: $\nabla_{b^{[1]}} L = \delta^{[1]}$、$\nabla_{b^{[2]}} L = \delta^{[2]}$

2. **連鎖律（Chain Rule）**:
   誤差逆伝播は微分の連鎖律に基づいています。各層のパラメータ（重みとバイアス）に関する誤差の勾配は、それより後の層の誤差を使って計算されます。

### 重みの更新（Weight Update）
勾配降下法を使用して、計算された勾配に基づいて重みとバイアスを更新します：

1. **勾配降下法（Gradient Descent）**:
   - 重みの更新: $W^{[l]} = W^{[l]} - \alpha \cdot \nabla_{W^{[l]}} L$
   - バイアスの更新: $b^{[l]} = b^{[l]} - \alpha \cdot \nabla_{b^{[l]}} L$

   ここで、$\alpha$は学習率で、更新の大きさを制御します。

2. **確率的勾配降下法（SGD）**:
   このプロジェクトでは、全データではなく、小さなバッチ（128サンプル）を使用して勾配を計算し、重みを更新しています。これにより、計算効率が向上し、局所最適解を回避する可能性も高まります。

3. **学習率の役割**:
   - 大きすぎる学習率: 収束が不安定になる、または発散する可能性がある
   - 小さすぎる学習率: 収束が非常に遅くなる
   - 適切な学習率（このプロジェクトでは0.5）を選ぶことが重要

## データセット

プロジェクトで使用されているデータセットは、時間単位の自転車レンタルデータで、以下の特徴を含みます：

- 時間帯、曜日、月、季節などの時間関連情報
- 天気状況、温度、湿度、風速などの環境情報
- カジュアル利用者数、登録利用者数、合計利用者数

データは標準化され、カテゴリカル変数はダミー変数に変換されています。また、データセットはトレーニング、検証、テストセットに分割されています。

## ニューラルネットワークの実装

ニューラルネットワークは以下の特徴を持ちます：

- **入力層**: 特徴量の数に応じたノード数
- **隠れ層**: 10個のノード（ハイパーパラメータとして設定）
- **出力層**: 1つのノード（自転車レンタル数の予測値）
- **活性化関数**: 隠れ層にはシグモイド関数、出力層には線形関数（f(x)=x）
- **学習率**: 0.5（ハイパーパラメータとして設定）
- **イテレーション数**: 4000（ハイパーパラメータとして設定）

## 実装の詳細

ニューラルネットワークの主要な実装は`my_answers.py`ファイルに含まれており、以下の主要なメソッドがあります：

1. **forward_pass_train**: 訓練時の前方伝播を実装
2. **backpropagation**: 誤差の逆伝播とデルタ重みの計算を実装
3. **update_weights**: 勾配降下法による重みの更新を実装
4. **run**: テスト時の前方伝播（予測）を実装

## トレーニングプロセス

ネットワークは確率的勾配降下法（SGD）を使用してトレーニングされています。各イテレーションでは、トレーニングデータからランダムに128個のサンプルが選ばれ、これらを使用して重みが更新されます。トレーニング中は、トレーニング損失と検証損失が追跡され、過学習が監視されます。

## 評価方法

モデルの評価は、テストデータセットを使用して行われます。予測値と実際の値が比較され、モデルの性能が視覚的に表示されます。評価指標としては平均二乗誤差（MSE）が使用されています。

## 注意点

コードを実行する際には、使用されているPandasのバージョンに注意が必要です。現在のコードでは`.ix`メソッドが使用されていますが、これは新しいバージョンのPandasでは廃止されています。代わりに`.loc`または`.iloc`を使用する必要があります。

## まとめ

このプロジェクトは、深層学習の基本的な概念を理解し実装するための良い練習となっています。ニューラルネットワークの基本構造、前方伝播と誤差逆伝播のアルゴリズム、重みの更新方法など、深層学習の基礎を学ぶことができます。また、実際のデータを使用することで、データ前処理や評価方法についても理解を深めることができます。
